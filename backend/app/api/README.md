# backend/app/api

rest.py는 게스트/헬스/랭킹, websocket.py는 Origin·토큰·스키마 검사와 연결별 송수신을 담당합니다. 서버 확정 위치는 클라이언트 메시지에서 받지 않습니다.

## 폴더 역할과 유지보수 안내

REST 게스트/건강상태/누적 랭킹과 WebSocket 게스트 인증/게임 요청 진입점.

[프로젝트 루트 안내](../../../README.md)에서 전체 구조와 실행 순서를 확인하세요.

### 바로 아래 파일

| 파일 | 역할 |
|---|---|
| [__init__.py](__init__.py) | REST 게스트/건강상태/누적 랭킹과 WebSocket 게스트 인증/게임 요청 진입점. 파이썬 패키지 진입 표시이며 실행 부작용은 없습니다. |
| [rest.py](rest.py) | 게스트 생성, 서버 상태 확인, DB 누적 랭킹 REST API. 실시간 월드 랭킹은 WS 스냅샷과 별개입니다. |
| [websocket.py](websocket.py) | 게스트 인증 후 이동·강화·리스폰 요청을 월드에 전달하고 개인별 스냅샷을 송신합니다. |

### 변경 시 점검

경로·환경변수·의존성을 변경하면 루트 실행 안내도 맞춰 주세요. 과거 검증 결과를 최신 결과로 표시하지 않으며 실행하지 않은 Docker/MySQL/외부 배포 검증은 미실행으로 남깁니다.
