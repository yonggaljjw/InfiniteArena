# backend/app/core

config.py의 Settings가 환경변수를 읽습니다. DATABASE_URL, ALLOWED_ORIGINS, MAX_PLAYERS(1~20)를 설정할 수 있습니다. 월드4096/서버20Hz/상태10Hz는 클라이언트와 맞춘 이 MVP의 고정 값으로 검증합니다.

## 폴더 역할과 유지보수 안내

서버 설정. .env/환경변수의 타입·제약 조건을 한 곳에서 관리합니다.

[프로젝트 루트 안내](../../../README.md)에서 전체 구조와 실행 순서를 확인하세요.

### 바로 아래 파일

| 파일 | 역할 |
|---|---|
| [__init__.py](__init__.py) | 서버 설정. .env/환경변수의 타입·제약 조건을 한 곳에서 관리합니다. 파이썬 패키지 진입 표시이며 실행 부작용은 없습니다. |
| [config.py](config.py) | 환경변수와 .env에서 서버 설정을 읽습니다. 월드 크기와 송신 주기는 현재 프로토콜의 고정값입니다. |

### 변경 시 점검

경로·환경변수·의존성을 변경하면 루트 실행 안내도 맞춰 주세요. 과거 검증 결과를 최신 결과로 표시하지 않으며 실행하지 않은 Docker/MySQL/외부 배포 검증은 미실행으로 남깁니다.
