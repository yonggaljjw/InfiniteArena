# backend/migrations/versions

0001_guests.py는 실제 guest_accounts 테이블과 인덱스를 생성합니다. 초기 DB revision은0001입니다.

## 폴더 역할과 유지보수 안내

순차 DB 스키마 이력. 기존 적용 revision 대신 새 revision으로 변경을 누적합니다.

[프로젝트 루트 안내](../../../README.md)에서 전체 구조와 실행 순서를 확인하세요.

### 바로 아래 파일

| 파일 | 역할 |
|---|---|
| [0001_guests.py](0001_guests.py) | 최초 게스트 계정 테이블과 닉네임 인덱스 생성. 이미 적용한 마이그레이션 변경 대신 새 revision을 추가하세요. |

### 변경 시 점검

경로·환경변수·의존성을 변경하면 루트 실행 안내도 맞춰 주세요. 과거 검증 결과를 최신 결과로 표시하지 않으며 실행하지 않은 Docker/MySQL/외부 배포 검증은 미실행으로 남깁니다.
