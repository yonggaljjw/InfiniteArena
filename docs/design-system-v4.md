# V4 UI 디자인 시스템

서버와 Phaser 월드를 유지하면서 Vue의 화면 공간 UI를 새로 구성했습니다. 외부 에셋 팩을 사용하지 않습니다. 석재·금속 패널은 CSS 그라디언트/이중 테두리/모서리로, 로고 문양과 게임 아이콘은 직접 작성한 24×24 SVG 경로로 구현했습니다. SVG는 crispEdges이며 게임의 V1~V3 PNG를 대체하지 않습니다. 원본 코드가 프로젝트에 포함됩니다. 기존 Noto Sans KR 의존성과 라이선스는 유지합니다.

## 공통 토큰

`frontend/src/ui/tokens.css`가 색상·패널·간격·애니메이션 곡선의 기준입니다. `game-ui.css`가 메뉴/HUD/오버레이와 반응형 배치를 담당하고 `style.css`는 토큰 가져오기와 전체 화면 기본값만 가집니다.

| 토큰 | 값 | 역할 |
|---|---|---|
| ink | #101417 | 전체 배경 |
| panel / panel-light | #171c20 / #252b2e | 차분한 흑석·금속 |
| line | #4f5148 | 구조 테두리 |
| gold / gold-muted | #d9b776 / #8f7954 | 레벨·선택·버튼·로고 |
| text / muted | #eeece4 / #a4aaa6 | 주 텍스트·보조 정보 |
| health | #cd5a58 | 붉은 HP |
| experience | #54b8b6 | 청록 EXP |
| danger | #e5968b | 오류와 사망 안내 |
| edge | 16~32px | 해상도별 화면 여백 |
| ui-scale | 0.9 / 1 / 1.15 / 1.25 | 사용자 UI 크기 |

패널에 불필요한 둥근 웹 카드 모양을 없애고 얇은 금속 모서리와 낮은 투명도를 적용했습니다. 본문은 Noto Sans KR, 로고와 숫자 강조는 시스템 Georgia/serif입니다. 추가 폰트 다운로드 없이 기존 파일을 사용합니다. 폰트/해상도별 렌더링의 완전한 동일성은 보장하지 않습니다.

## 화면 구성

- 좌측 상단: 닉네임·레벨·HP·EXP. 바와 수치는 동일 스냅샷에서 계산합니다.
- 상단 중앙: 작은 접속 상태·설정·나가기/재접속. 화면 전체 폭의 웹 내비게이션을 제거했습니다.
- 우측 상단: 서버 상위5명·접속 인원. 본인을 ID로 강조합니다. 목록 밖이면 정확한 순위 대신 '상위5위 밖'을 표시합니다.
- 좌측 하단: 실제 무기 목록·해금/자동 공격·총알 피해/공격 간격/속도·보호 상태.
- 우측 하단: 서버 킬 피드 최근3개. 장식만 추가하고 이벤트 내용은 바꾸지 않습니다.
- 강화: 아래쪽의3카드. 선택 중 전투가 진행되며 일반 하단 패널/도움말을 잠시 숨겨 겹침을 줄입니다.
- 사망: 중앙의 작은 오버레이와 절제된 음영. Phaser Scene과 네트워크를 정지하지 않습니다.
- 메뉴: 실제 월드를 배경으로 암부/비네트를 추가한 로고·입장·설정 화면. 별도 가짜 서버 연결 상태를 표시하지 않습니다.

기본 HUD의 중앙 전투 공간은 비워 두며 배경 패널은 pointer-events:none입니다. 조작 가능한 버튼과 강화/사망 화면만 포인터를 받습니다. 설정은 의도적인 모달이며 게임 입력을0으로 보내지만 서버 시뮬레이션을 멈추지 않습니다.

## 절제된 모션

HP/EXP 바180ms, 메뉴220ms, 오버레이180ms, 랭킹 이동250ms, 레벨 강조350ms입니다. 수치·접속·보상은 즉시 서버 값을 사용하고 CSS가 바의 표시만 보간합니다. EXP는 레벨을 key로 새로 생성해 레벨업 때 이전 레벨에서 줄어드는 바를 잘못 보간하지 않습니다. 카드 선택의 서버 응답 전 강조는 요청 상태이며 실제 강화 완료로 표시하지 않습니다.

동작 감소 설정은 UI 전환을 사실상 즉시 처리합니다. 최초값은 시스템 prefers-reduced-motion을 읽고, 이후 사용자의 명시적 선택을 따릅니다. 이 설정은 V3 월드 파티클/화면 흔들림의 별도 품질 설정을 바꾸지 않습니다.

## 접근성·해상도

실제 label/input/button/select/checkbox를 사용하고 키보드 focus-visible 테두리를 제공합니다. 설정은 dialog/aria-modal·Escape 닫기·Tab 순환·이전 포커스 복원으로 구성했습니다. 닉네임 WASD 문자가 Phaser 입력 캡처로 막히지 않도록 native 입력을 유지합니다. 메뉴 오류는 role=alert, HP/EXP는 실제값을 가진 progressbar로 노출합니다. 10Hz HP/랭킹에 과도한 aria-live 알림은 적용하지 않습니다.

1920×1080,2560×1440,1366×768와 UI100%/125% 배치, 125% 브라우저 확대에 해당하는1093×614 CSS viewport를 검사합니다. 실제 브라우저 메뉴의 확대 버튼을 조작한 검사는 아니며 CSS viewport 축소 등가 검사입니다. 1920/2560에서 충분한 PC 시야를 확보하고 작은 높이는 메뉴/설정 내부 스크롤로 입력을 접근 가능하게 합니다. 760px 이하 보조 배치도 있지만 모바일 터치 조작은 구현 범위가 아닙니다.
