# V2 에셋 명세와 제작 출처

## 실제 PNG

| 경로 (frontend/public 기준) | 크기 | 런타임 사용 |
|---|---|---|
| assets/characters/player-source-v2.png | 1254×1254 RGBA | 재가공 원본, 미로딩 |
| assets/characters/player-v2.png | 512×512 RGBA | 플레이어 64프레임 |
| assets/monsters/ghoul-source-v2.png | 2172×724 RGBA | 재가공 원본, 미로딩 |
| assets/monsters/ghoul-v2.png | 512×512 RGBA | 기존 일반 몬스터 64프레임 |
| assets/animations/entity-v2.json | 프레임·경로·검사 명세 | Vite JSON import로 번들에 포함 |

내장 Imagegen으로 새로 생성한 방어구·청록색 망토의 플레이어와 회청색 피부·뼈·황색 눈의 숲 구울입니다. 외부 게임의 캐릭터나 상용 팩을 가져오지 않았습니다. 별도 외부 에셋 라이선스를 부여한 것으로 주장하지 않습니다. 생성 서비스의 이용 조건이 적용됩니다. 기존 V1 리소스와 폰트/패키지 라이선스는 그대로 유지합니다.

전체 생성 프롬프트는 `docs/imagegen-prompts-v2.json`에 있습니다. 이미지 생성 API 호출은 게임 실행에 필요하지 않습니다.

## 정확한 프레임 배열

캔버스64×64, 시트8열×8행, 여백 포함, origin(0.5,0.5), 표현 배율1. 발 기준은 프레임(32,48), 서버 중심(x,y)에 대해 월드 발 위치(y+16)입니다. 서 있는 실제 본체 높이는 약44px입니다. 서버 충돌 반경12는 그림 크기와 독립적이며 변경하지 않았습니다.

| 방향 | 전체 프레임 범위 | Idle | Walk | Hit | Death |
|---|---|---|---|---|---|
| Down | 0–15 | 0–3 | 4–9 | 10–11 | 12–15 |
| Left | 16–31 | 16–19 | 20–25 | 26–27 | 28–31 |
| Right | 32–47 | 32–35 | 36–41 | 42–43 | 44–47 |
| Up | 48–63 | 48–51 | 52–57 | 58–59 | 60–63 |

Idle4fps, Walk9fps(실제 화면 이동 속도/기준 속도로 timeScale0.65–1.65), Hit10fps200ms, Death8fps500ms 마지막 프레임 확정 후700ms까지 페이드합니다. Idle/Walk만 무한 반복합니다. 처음 접속 및 리스폰에는 약280ms 알파와 접지 그림자 크기 변화가 적용됩니다.

## 원본의 제한과 정규화

생성 모델이 플레이어 요청의8×8 격자를 지키지 않아 원본은 방향별 두 줄씩 약13포즈를 포함합니다. 방향별 첫 줄에서 육안으로 확인한 포즈를 추출했습니다. 몬스터는12열×4행이며 좌/우 원본 행을 서로 교환해 실제 얼굴 방향과 일치시켰습니다. 셀의 투명 여백을 제거하고 방향별 동일 배율로 nearest-neighbor 축소, 발 기준 정렬, 고정64px 캔버스에 재배치합니다.

프레임 수와 독립적으로 그려진 포즈 수는 다릅니다. 플레이어 Walk는5개 원본 포즈와 루프 연결용1개 반복, Hit의 첫 포즈는 걷기 포즈를 재사용하고 둘째는 움츠리는 포즈입니다. 몬스터 Idle은3개 포즈+1개 반복, Walk는5개+1개 반복, Death는3개+마지막 포즈 유지입니다. 시트에 없는 독립 원화를 제작했다고 주장하지 않습니다. 매핑은 JSON의sourcePoseIndices와 빌드 스크립트에 기록했습니다. 원본의 가는 디테일은 축소되어 완전 수작업64px 픽셀 아트와 차이가 있습니다.

```bash
python -m pip install -r tools/requirements.txt
python tools/build_entity_atlases.py
```

정규화 결과2개PNG와JSON이 이미 포함됩니다. Docker/브라우저 실행에는 Pillow가 필요하지 않습니다. 텍스처 실패 시에만 최소 대체 도형을 생성하고 경고를 출력합니다. 이 경로는 게임 실행 유지용이며 V2 그래픽 완성품으로 간주하지 않습니다.
