# frontend/public/assets/environment

source-atlas-v1.png는 실제 Imagegen 원본입니다. fir/oak-canopy는 단단한 밑동 없이 통행 가능한 전경 장식으로 사용합니다.

## 폴더 역할과 유지보수 안내

V1 환경 원본 아틀라스와 무충돌 나무 수관. 독립 수관은 장식이며 장애물 추가가 아닙니다.

[프로젝트 루트 안내](../../../../README.md)에서 전체 구조와 실행 순서를 확인하세요.

### 바로 아래 파일

| 파일 | 역할 |
|---|---|
| [fir-canopy-v1.png](fir-canopy-v1.png) | 게임에 로딩하는 PNG 리소스. 프레임/크기와 적용 범위는 관련 에셋 명세를 확인하세요. |
| [oak-canopy-v1.png](oak-canopy-v1.png) | 게임에 로딩하는 PNG 리소스. 프레임/크기와 적용 범위는 관련 에셋 명세를 확인하세요. |
| [source-atlas-v1.png](source-atlas-v1.png) | 제작 원본 PNG. 런타임용 출력 파일/가공 방법과 사용 범위는 이 폴더의 에셋 설명을 확인하세요. |

### 변경 시 점검

공개 URL은 `/assets/...`입니다. JSON에는 주석을 넣지 말고 이 문서에서 구조를 설명합니다. 원본/프레임 정의/로더를 함께 맞추고 에셋 제작 스크립트 실행은 PNG를 덮어쓸 수 있으므로 결과를 비교합니다. 기존 출처·사용 범위 설명을 유지하세요.
