# V3 projectile PNGs

own/hostile/spread-bolt는오른쪽을향한32×16PNG입니다. 서버vx/vy로회전하며이미지크기와충돌반경은독립적입니다. orbit-blade는32×32이며기존서버orbit_angle/반경70을그대로사용합니다. 서버owner가있어야본인/타인구분이정확합니다. 새로운물리바디는없습니다.

## 폴더 역할과 유지보수 안내

V3 본인·타인·확산탄·회전 무기 PNG. 종류와 소유자는 서버 상태에서 읽습니다.

### 변경 시 점검

공개 URL은 `/assets/...`입니다. JSON에는 주석을 넣지 말고 이 문서에서 구조를 설명합니다. 원본/프레임 정의/로더를 함께 맞추고 에셋 제작 스크립트 실행은 PNG를 덮어쓸 수 있으므로 결과를 비교합니다. 기존 출처·사용 범위 설명을 유지하세요.
