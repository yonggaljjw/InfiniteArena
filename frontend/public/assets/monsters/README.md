# Normal monster V2

ghoul-v2.png는현재 서버의 유일한 일반 몬스터용64px 프레임64개 시트입니다. 빠른/강력한 몬스터는없습니다. ghoul-source-v2.png는생성 원본으로 런타임에서로드하지 않습니다. 좌/우 원본 행을 방향에맞게 교환했습니다. 프레임 재사용·출처는docs/assets-v2.md.

## 폴더 역할과 유지보수 안내

기존 일반 몬스터의 V2 원본/시트. 서버에 없는 빠른/강력 몬스터 종류는 구현하지 않았습니다.

[프로젝트 루트 안내](../../../../README.md)에서 전체 구조와 실행 순서를 확인하세요.

### 바로 아래 파일

| 파일 | 역할 |
|---|---|
| [ghoul-source-v2.png](ghoul-source-v2.png) | 제작 원본 PNG. 런타임용 출력 파일/가공 방법과 사용 범위는 이 폴더의 에셋 설명을 확인하세요. |
| [ghoul-v2.png](ghoul-v2.png) | 게임에 로딩하는 PNG 리소스. 프레임/크기와 적용 범위는 관련 에셋 명세를 확인하세요. |

### 변경 시 점검

공개 URL은 `/assets/...`입니다. JSON에는 주석을 넣지 말고 이 문서에서 구조를 설명합니다. 원본/프레임 정의/로더를 함께 맞추고 에셋 제작 스크립트 실행은 PNG를 덮어쓸 수 있으므로 결과를 비교합니다. 기존 출처·사용 범위 설명을 유지하세요.
