# frontend/public/assets/props

fir/oak/dead-tree,boulder,pillar,wall,rubble PNG입니다. 큰 본체는 서버의 기존 장애물에만 배치합니다. 작은 rubble 파편은 충돌 없는 지면 장식입니다.

## 폴더 역할과 유지보수 안내

V1 나무·바위·기둥·벽·잔해 PNG. 충돌하는 본체는 서버 장애물 좌표에 맞춰 배치합니다.

[프로젝트 루트 안내](../../../../README.md)에서 전체 구조와 실행 순서를 확인하세요.

### 변경 시 점검

공개 URL은 `/assets/...`입니다. JSON에는 주석을 넣지 말고 이 문서에서 구조를 설명합니다. 원본/프레임 정의/로더를 함께 맞추고 에셋 제작 스크립트 실행은 PNG를 덮어쓸 수 있으므로 결과를 비교합니다. 기존 출처·사용 범위 설명을 유지하세요.
