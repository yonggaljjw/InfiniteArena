# audio/bgm

| 파일(각 OGG/MP3) | 사용 | 제작 |
|---|---|---|
| menu | 최초 메뉴·닉네임·월드 퇴장 | 32초, 낮은 드론·마이너 화성·느린 플럭·절제된 잔향 |
| world | 월드 입장·탐험·현재 전투 | 32초, 더 빠른 플럭·낮은 프레임 드럼 |

원본 합성, 22,050Hz 스테레오. 소스는 tools/build_audio_assets.py입니다. 무한 루프와 900ms 교차 페이드는 오디오 서비스가 담당하며 각 곡 객체는 하나만 생성합니다. 숨긴 탭에서는 재생 위치를 유지해 일시정지하고 복귀 시 복원합니다.

Intense Combat 곡은 미구현입니다. 현재의 발사 빈도만으로 안정적인 전투 강도를 판정하지 않으며 한 발마다 음악을 바꾸지 않습니다. 메뉴/월드 우선 범위를 완성합니다. [사용 범위](../README.md).
