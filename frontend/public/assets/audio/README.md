# frontend/public/assets/audio

실제 재생 가능한 V5 OGG/MP3 음원과 manifest입니다. BGM 2곡 + SFX 16종, 각 형식별 18개로 총36파일입니다. 각 폴더의 README에 파일 목록이 있습니다.

| 경로 | 책임 |
|---|---|
| bgm/ | 32초 스테레오 메뉴·월드 반복 음악 |
| sfx/ | 45~900ms 모노 전투·보상·UI 효과음 |
| manifest-v5.json | URL, 길이, 채널, 우선순위, 쿨다운, 동시 수, gain, 파일 크기/SHA256 |

## 출처·사용 범위

이 프로젝트의 `tools/build_audio_assets.py`에서 직접 작성한 화성·멜로디·파형·노이즈로 생성한 원본 합성 음원입니다. 외부 녹음, 음원 샘플, 기존 곡, 다운로드 에셋을 사용하지 않았습니다. 본 패키지의 이 폴더 내 생성 음원은 게임 내 사용, 상업적 사용, 수정 및 재배포를 허용하며 별도 출처 표시를 요구하지 않습니다. 외부 에셋의 라이선스를 확보했다는 주장은 하지 않습니다. 이 허용 범위는 V1~V4 이미지나 프로젝트의 다른 파일에 대한 라이선스 변경을 의미하지 않습니다.

OGG 우선, OGG 미지원 환경에서는 MP3를 Phaser가 선택합니다. URL 배열은 지원 포맷 선택이며, 선택된 파일이 네트워크 오류를 일으켰을 때 다음 URL로 자동 재시도하는 기능은 아닙니다. 누락 음원은 생략하고 게임을 계속합니다. 두 BGM 중 하나만 있으면 가능한 트랙으로 대체합니다.

22,050Hz. 두 BGM의 디코딩 메모리는 약10.8MiB(스테레오 float32)이며 SFX를 포함하면 약11~12MiB입니다. 배포 용량은 두 형식을 모두 포함해 약1.16MB입니다. MP3/OGG 헤더와 손실 압축으로 가장자리 파형은 원본과 다를 수 있어 30ms 테이퍼를 적용했습니다. 수치적 경계 검증과 사람의 청취 평가는 구분합니다.
