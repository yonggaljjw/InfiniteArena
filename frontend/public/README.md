# frontend/public

Vite가 이 폴더를 dist로 그대로 복사합니다. 실제 환경 PNG가 assets 아래에 포함되어 있어 외부 에셋 서버가 필요하지 않습니다.

## 폴더 역할과 유지보수 안내

Vite가 경로를 보존하여 dist로 복사하는 공개 정적 파일. /assets/... URL로 읽습니다.

[프로젝트 루트 안내](../../README.md)에서 전체 구조와 실행 순서를 확인하세요.

### 바로 아래 파일

| 파일 | 역할 |
|---|---|

### 하위 폴더

| 폴더 | 역할 |
|---|---|
| [assets](assets/README.md) | V1/V2/V3 PNG와 생성 명세. 원본 이미지와 게임 로딩용 출력 파일을 함께 보관합니다. |

### 변경 시 점검

공개 URL은 `/assets/...`입니다. JSON에는 주석을 넣지 말고 이 문서에서 구조를 설명합니다. 원본/프레임 정의/로더를 함께 맞추고 에셋 제작 스크립트 실행은 PNG를 덮어쓸 수 있으므로 결과를 비교합니다. 기존 출처·사용 범위 설명을 유지하세요.
